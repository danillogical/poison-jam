## Stack/CFG model: competing hypotheses and recommended starting choices

Use `d = ESP - ESP_at_entry`, initially **0**; the incoming return address is already on the stack. Carry an exact/unknown abstract state, with an affine entry-relative frame register where supported. Preserve predecessor witnesses and deterministic ordering; bound work and report limits explicitly.

- **`call` is not universally depth-neutral.** Its temporary return-address push/pop cancels on return, but a callee's `ret N` adds **N** at the caller successor; caller cleanup remains an ordinary subsequent `add esp,N`. Derive summaries from justified reachable original exits/known ABI contracts, not the metadata being validated or the first linear `ret`. Unknown indirect-call cleanup must produce an explicit unknown state unless a bounded target set or verified contract resolves it. Also distinguish no-return calls and call/pop idioms. A naïve “all calls neutral” model should fail the callee-cleanup controls.
- **`ret N`:** normally require `d == 0` immediately before `ret`, then total delta is `4+N`; compare reachable `N` values with `stack_args` (default 0), independently of manifest claims. Unsupported stack-return manipulation is UNKNOWN, not an invented ABI failure. `push/pop`, `sub/add esp`, `lea esp`, frame setup/restoration and `leave` need correct transfers. Dynamic alignment/allocation, register-dependent ESP writes and unusual returns need a stated limitation or a tested transfer rule.
- **Tail `jmp`:** an external branch is not automatically a tail call just because its VA resolves. For an independently justified entry, compose the target cleanup contract; ordinary same-contract tails leave at `d==0`. Argument-reshaping tails can legitimately differ, so adjudicate by the composed contract rather than banning all nonzero tails. Nonzero-depth branches to a nearby continuation/shared epilogue are strong boundary evidence, not permission to call another wrapper. Unresolved tails remain explicit open edges.
- **SEH:** `push -1`, `push handler`, saved chain pointer and saved registers are real stack consumption, not special no-ops. `fs:[0]` stores do not change ESP. Track normal reachable control flow first; describe exceptional-handler coverage separately. The `0x80BD0` normal path must close `-0x40 + 0x44 = +4`. Do not pretend this is a complete SEH correctness audit.
- **Reachability, not linear sums:** explore both conditional successors and stop at return/unconditional transfer/verified no-return terminal. Do not execute unreachable bytes after `ret`, jump tables, padding, or a neighboring prologue as part of the entry. Verify instruction boundaries and detect overlapping reachable decodes. The wrong `0x80340` widening must not borrow `0x80BD0`'s unreachable `ret` to infer cleanup. A reachable end/fallthrough is different from harmless unreachable trailing bytes.
- **Jump tables and aliases:** recover targets only with validated table shape/bounds and mapped bytes; unresolved indirect jumps are UNKNOWN, not successful terminal exits. A folded alias resolving to its owner's symbol is not proof of a genuine function entry, while genuine manual/CRT symbols need not use `sub_VA` naming. Keep source-CFG ownership separate from runtime dispatch identity. Cross-entry incoming-edge/table-pointer evidence can identify suspicious entry roots or four-way join labels; a prologue pattern or lack of callers alone cannot.
- **Join depth:** differing precise incoming states must be detected with witness paths, not averaged or erased. Distinguish a supported contradictory stack contract from potentially infeasible branch combinations, intentional stack reshaping, or unknown transfers. If such distinctions dominate the census, ask the Advisor before expanding the gate's hard-fail class.

Suggested vocabulary: **PROVED** (all modeled reachable paths checked; state claim limits), **DEFECT** (specific supported counterexample with VA/edge/expected/actual), **SUSPICIOUS** (boundary/entry/dispatch evidence needing adjudication), **UNKNOWN** (unsupported transfer, cleanup, target, or limit), and **INPUT_ERROR**. Fail the gate for proven defects and invalid/missing mandatory inputs; UNKNOWN is never PROVED but need not fail the entire existing population. Retain independent proven defects even when another path is unknown. Summarize counts/reasons instead of thousands of warnings. Track whether changed entries lose previously proved coverage. No address-specific logic; addresses belong only in regression selection/evidence.
