# OMP execution policy

- Plan at the start of every substantive engineering session using the configured
  plan role. Enter plan mode explicitly; assigning the role alone does not invoke it.
  If that role is unavailable, report the failure without substituting another route.
- After planning, the primary agent owns ordinary technical decisions and adapts
  the plan to measured evidence. Read `AGENTS.md` and `plan-jsrf-gameplay.md` first.
- Both the game and sibling toolkit may be edited. Build, run and validate on Windows;
  validate the final durable tree and distinguish observations from inference.
- Preserve original assets, existing saves and unrelated edits. Never force-push.
- Commit verified work; when both repositories change, push toolkit first, then game.
- Stop at a clean useful baseline when the next task is a separate substantial problem.
