The static slice must provide the feasible-path argument; in-range B9 reads and existing table-driven MIXBUF consumption are not themselves reliance on the doorbell. No device model, strict doorbell claim, audio correctness, VP work, spin exit or liveness is established. No MIXBUF value-model; no premature `0xFFFFB3` model. Register identification remains `UNRESOLVED` unless separately supported by qualifying sources; no external-source search is needed for this follow-up's two-leg decision.
- Stop/choose `O-INCONCLUSIVE` on changed pins without repin, incomplete first exchange, missing/lossy trace, count mismatch, unexplained indirect edge or descriptor alias, altered table execution, gate leakage into absent-env control, or an out-of-scope write. A valid refutation already observed takes precedence. `diagnostic_deadline` is only a bound, and exploratory/fixture runs are **knowledge only**: no strict criterion is satisfied and nothing is claimed to work.
